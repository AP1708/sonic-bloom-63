# Harmony Hub (79)

Build a modern music streaming web application inspired by the user experience of Spotify and YouTube Music. Use React, TypeScript, Tailwind CSS, and Supabase. Create a responsive dark UI with authentication, user profiles, home dashboard, search, playlists, liked songs, recently played, library, queue, lyrics panel, mini player, fullscreen player, settings, and AI-powered recommendations. Integrate the Spotify Web API for music metadata and playback where supported, and the YouTube Data API plus YouTube IFrame Player API for searchable videos and embedded playback. Include global search across both sources with filters, smooth animations, offline-ready caching for app data (not copyrighted media), collaborative playlists, notifications, and an admin dashboard. Structure the code with reusable components, clean state management, API abstraction layers, error handling, and scalable architecture. Ensure all integrations use official APIs and comply with their respective platform terms.
